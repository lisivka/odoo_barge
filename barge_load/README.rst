Barge Load Management
=====================

The Barge Load Management module is designed to streamline and manage barge loading operations, with a focus on tracking loading activities, captains, agents, and dredgers. This module provides custom menus, models, and user groups to enhance operational efficiency in the dredging and barge transport sectors.

Key Features
------------
* Custom models for Barges, Captains, Agents, Quarries, and Dredgers.
* Integration with Odoo's security groups and permissions.
* Role-based access for Administrators, Managers, and Agents.
* Wizards for bulk updates of records and mass report generation.
* Detailed record of barge load activities and agent assignments.
* Multiple views such as form, tree, kanban, pivot, and calendar.
* Report generation capabilities for barge load acts.

Requirements
------------
* Odoo version 17.0 or higher.
* Required modules: ``base``, ``mail``.

Installation
------------
1. Download the module and place it in your Odoo addons directory.
2. Update the app list by navigating to Apps and clicking "Update Apps List".
3. Search for "Barge Load Management" and install the module.

Usage
-----
After installing the module, you will have access to:
* A custom menu "Barge Management" with submenus for Barges, Captains, Agents, Quarries, and Dredgers.
* Access to detailed barge load records, loading acts, and the ability to link agents and captains to each load.
* Bulk actions via wizards to manage records and generate reports.
